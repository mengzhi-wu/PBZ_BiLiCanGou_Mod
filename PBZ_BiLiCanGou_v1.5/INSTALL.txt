影之刃零「别离残钩」机制优化 Mod v1.5（正式版）
=========================================

一共三个傻瓜按钮，双击就行：install.bat / check.bat / uninstall.bat

一、前置（只做一次）
  1) 完全关闭游戏
  2) 装 UE4SS for Phantom Blade Zero（Nexus: phantombladezero/mods/14）
     解压到 ...\steamapps\common\PBZ\platform\steam\
     （必须和 PBZ.exe 同级，不是游戏根目录）

二、安装（你只需要告诉它游戏装在哪）
  1) 双击 install.bat
  2) 窗口会提示：把《影之刃零》的游戏根目录拖进来后回车
     不知道在哪？一般是  ...\Steam\steamapps\common\PBZ
     也可以直接回车，会弹文件夹选择框；输入 Q 退出
  3) 脚本自己找到 PBZ.exe 和 ue4ss，然后：
       - 校验路径对不对（不对会让你重试，最多三次）
       - 检查 ue4ss 是否已装（没装会提示你先装，可选继续或取消）
       - 复制 mod 到 ue4ss\Mods\PBZBiLiCanGou
       - 旧版本备份成 PBZBiLiCanGou.bak-时间戳
       - 写好 enabled.txt，并把 mods.txt 改成 PBZBiLiCanGou : 1（改前备份）
       - 记住这次的目录，下次卸载/体检不用再输

  也可以一条命令给路径（写进快捷方式很方便）：
    install.bat "D:\SteamLibrary\steamapps\common\PBZ"
    根目录 / platform\steam / ue4ss 给哪层都能认

三、检查装好没有
  双击 check.bat
  逐项 [OK] 就说明齐了；哪项 [ !] 或 [ X]，按提示处理。

四、第一次进游戏（建议顺序）
  1) 进游戏后按 F7 —— 把接口诊断写进日志（不弹界面）
     热键：F1 杀气返还开/关，F2 瞬时反制开/关（按下时屏幕提示状态），F9 紧急停止
  2) 控制台输 pbzkg probe —— 把真实符号名（组件/动作/武器/背包）写进日志
     哪项显示未找到/缺失/nil，就把 probe 那段发给作者
  3) 控制台输 pbzkg dryrun —— 打一场，看日志里的 [DRY-RUN] 返还是否合理
  4) 再输一次 pbzkg dryrun 关掉，正式生效

五、热键与命令
  F7  状态面板
  F8  杀气返还开/关（也能解除「连续失败自动停写」）
  F9  紧急停止/解除
  pbzkg status | on | off | auto on/off | dryrun | panic | probe | reload

六、只保留一个功能
  只要杀气返还、不让它替你按键:
      Scripts\config.lua 里 instant_counter.enabled = false
  只要瞬时反制、不要动杀气:
      pbzkg off，或 config.lua 里 refund.enabled = false

七、卸载
  双击 uninstall.bat
  它沿用上次安装时记下的目录（没记录会问你一次），确认一次后执行：
  删掉 mod 目录、清掉 mods.txt 里那一行（改前备份），游戏本体和存档不动。

八、脚本跑不起来
  - 提示 running scripts is disabled:
      在该文件夹 Shift+右键 -> 在此处打开 PowerShell，执行
      powershell -ExecutionPolicy Bypass -File .\tools\PBZModSetup.ps1
  - 提示「这个路径里没找到 PBZ.exe」: 选到游戏安装目录（...\steamapps\common\PBZ）再试
  - 杀毒软件提示脚本在改文件: 正常（要复制 mod 并改 mods.txt），放行即可

九、注意
  - 单人游戏使用；不写存档、不改游戏本体文件
  - 安装时游戏必须完全退出，否则文件被占用
  - 与「自动防御」类 mod 同开会抢按键，建议二选一
  - 游戏更新后先确认 UE4SS 还能加载（日志里有 GUObjectArray address）
